# Morphir site theme

Adapted from `apps/morphir-site/assets/site.css` in FINOS
[morphir-moonbit](https://github.com/finos/morphir-moonbit/blob/bd3adc52e6b8f6368fdaee50f76535799732f8d6/apps/morphir-site/assets/site.css),
revision `bd3adc52e6b8f6368fdaee50f76535799732f8d6`, under Apache-2.0.
Source SHA-256: `9ade4dbd64887a5c04b4832dc59a1338cb589595a693d6970f46ba28665187ff`.

The blue/orange palette, responsive hero, code window, pipeline and feature
cards follow that reference. The final aliases connect Telescope shell tokens
to the same palette. The renderer and browser controls remain stock Telescope.
The build appends this stylesheet before validation and atomic promotion.
